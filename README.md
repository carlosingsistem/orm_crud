# ✨ ORM CRUD

Una aplicación web simple que demuestra las operaciones CRUD (Crear, Leer, Actualizar, Borrar) utilizando un ORM (Object-Relational Mapping) en Python.

## 📜 Descripción

Este proyecto es una aplicación de ejemplo para gestionar productos utilizando la dpendencia de sqlalchemy de flask, usando sqlite como base de datos.

## 📜 Características

-   **insert_product:** Añadir nuevos productos.
-   **query_products:** Mostrar una lista de todos los productos y ver detalles individuales.
-   **update_product:** Modificar la información de los productos existentes.
-   **delete_product:** Eliminar un producto.
-   **init_database:** Inicializa la base de datos y cra la tabla Product
